# ОНА. ОТКРЫТАЯ. — бот «7 дней. Путь к Ясности»

Телеграм-бот [@Clarity7DaysBot](https://t.me/Clarity7DaysBot) для курса «7 дней. Путь к Ясности».
Канал: [t.me/onaotkrytaya](https://t.me/onaotkrytaya).

## Как работает бот

1. `/start` — приветствие от «ОНА. ОТКРЫТАЯ.».
2. «Как устроен путь» — описание 7 дней и дисклеймер «это не психотерапия».
3. «Начать День 1 — бесплатно» — сразу приходит первый день.
4. После дня 1 — предложение открыть дни 2–7 за 990 ₽.
5. После оплаты следующий день приходит утром следующего дня (по умолчанию в 9:00 по Москве), и так до 7-го дня.
6. «Мои дни» (`/days`) — можно открыть любой уже полученный день снова.
7. После 7-го дня оплатившие путь получают секретный подарок — трекер на 30 дней (PDF).
8. Трекер можно купить и отдельно: `/tracker` или ссылка `t.me/Clarity7DaysBot?start=tracker` (цена `TRACKER_PRICE_RUB`, по умолчанию 490 ₽; для звёзд — `TRACKER_STARS_PRICE`).

Прогресс хранится в базе данных: перезапуск бота ничего не стирает, и один день никогда не приходит дважды.

## Где лежат тексты

- `content/day1.md` … `content/day7.md` — уроки. Части урока разделены строкой `---`, каждая часть — отдельное сообщение. Первая строка `# …` — название дня для меню.
- `content/audio/` — сюда кладутся аудиопрактики: `day1.mp3`, `day2.mp3`, … Пока файла нет, бот отправляет текст практики.
- `bot/texts.py` — тексты воронки: приветствие, описание, предложение, сообщения после оплаты.

Разметка — Telegram HTML: `<b>жирный</b>`, `<i>курсив</i>`.

## Режимы оплаты (`PAYMENT_MODE`)

- `test` — у администраторов (`ADMIN_IDS`) вместо оплаты кнопка «Открыть дни 2–7 (тестовый доступ)», деньги не списываются. Все остальные видят обычную цену и ответ «оплата скоро откроется» (бот запоминает, кто хотел купить).
- `off` — кнопка «Продолжить путь — 990 ₽» отвечает, что оплата скоро откроется, и запоминает, кто хотел купить (видно в `/stats`). Для живого запуска до подключения оплаты.
- `yookassa` — оплата картой / СБП через ЮKassa прямо в Telegram. Нужен `YOOKASSA_PROVIDER_TOKEN` (@BotFather → бот → Payments → ЮKassa).
- `stars` — оплата звёздами Telegram. Нужен `STARS_PRICE`.

Что выбрать — в `docs/marketing/strategy.md`, раздел 6. Перед реальными продажами — чек-лист в `docs/legal/README.md` (оферта, политика данных, `OFFER_URL`, `PRIVACY_URL`, `SUPPORT_CONTACT`).

Возврат: администратор пишет боту `/refund <Telegram ID>`. Звёзды возвращаются автоматически; оплату ЮKassa бот помечает возвращённой, а деньги возвращаются в кабинете ЮKassa. Выдача следующих дней останавливается.

## Запуск на Amvera (российский хостинг, оплата картой РФ)

В репозитории уже есть файл `amvera.yml` с настройками. База данных хранится в постоянной папке `/data` и не стирается при обновлениях, поэтому отдельная PostgreSQL не нужна.

1. Зарегистрируйся на amvera.ru и пополни баланс.
2. **Создать проект** → тип «Приложение» → название, например `clarity-bot` → выбери тариф (для одного бота хватит самого маленького).
3. Подключи код: выбери подключение репозитория GitHub `kamiloskina/yasnost`, ветка `main`. Если такой опции нет — загрузи файлы репозитория через интерфейс (скачай ZIP с GitHub: Code → Download ZIP).
4. На шаге конфигурации Amvera подхватит `amvera.yml`. Если попросит заполнить вручную: окружение **Python**, менеджер **pip**, версия **3.12**, файл зависимостей `requirements.txt`, скрипт `main.py`, постоянное хранилище `/data`.
5. В проекте открой **Переменные**. Токен добавь как **секрет**, остальное — как обычные переменные:

| Имя | Значение |
|---|---|
| `BOT_TOKEN` (секрет) | токен из @BotFather |
| `PAYMENT_MODE` | `test` |
| `ADMIN_IDS` | твой Telegram ID (@userinfobot) |
| `AUTOPOST` | `true` |
| `CHANNEL_ID` | `@onaotkrytaya` |

6. Нажми **Пересобрать / Перезапустить**. В логах должна появиться строка `bot started`.
7. Напиши боту `/start`, затем `/autopost`.

Если сборка падает с ошибкой конфигурации — открой в Amvera вкладку конфигурации, сгенерируй `amvera.yml` их конструктором с параметрами из шага 4 и пришли мне текст ошибки.

## Запуск на Railway (альтернатива)

1. В Railway открой проект бота → сервис → **Variables** и задай:
   - `BOT_TOKEN` — токен из @BotFather (в чат и в код его не вставлять);
   - `PAYMENT_MODE` — `test`;
   - `ADMIN_IDS` — твой Telegram ID (узнать: @userinfobot), чтобы работала `/stats`.
2. Добавь базу: **New → Database → PostgreSQL**. В Variables сервиса бота добавь `DATABASE_URL` со значением `${{Postgres.DATABASE_URL}}`.
   Без PostgreSQL бот использует файл SQLite, который на Railway стирается при каждом обновлении.
3. Railway сам установит зависимости из `requirements.txt` и запустит `worker: python main.py` из `Procfile`.

Важно: бот с одним токеном может работать только в одном месте. Если старая версия ещё где-то запущена, останови её.

## Команды администратора (только для `ADMIN_IDS`)

Обычные пользователи эти команды не видят в меню, а если наберут вручную — бот их молча игнорирует.

- `/next` — сразу открыть следующий день, не дожидаясь утра;
- `/reset` — стереть свой прогресс и тестовую покупку, начать заново.

Для администратора (`ADMIN_IDS`): `/stats` — воронка и источники; `/autopost` — состояние автопостинга, права бота в канале и ближайшие посты; `/audio` — загрузить аудиопрактику дня (выбираешь день, отправляешь боту MP3 или голосовое; сценарии для записи — `docs/audio-scripts.md`); `/voice` — прикрепить к посту голосовое или кружок (записываешь прямо в чате с ботом, оно выйдет в канал перед текстом поста); `/refund <Telegram ID>` — возврат за путь, `/refund <Telegram ID> tracker` — за трекер.

Для всех: `/terms` — условия и возврат, `/paysupport` — вопросы по оплате.
