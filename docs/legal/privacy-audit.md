# Аудит privacy.md и реализации бота (152-ФЗ)

Дата: 08.11.2026. Проверена редакция политики от 07.11.2026 и код бота.

> **Ограничение.** Официальные источники (pravo.gov.ru, КонсультантПлюс, Гарант, pd.rkn.gov.ru) из среды разработки **недоступны**. Действующие редакции норм на 08.11.2026 не сверены. Номера статей и сроки приведены по известным редакциям 152-ФЗ с изменениями Федерального закона № 266-ФЗ. Выводы с пометкой `LEGAL_REVIEW_REQUIRED` подтверждает юрист.

## 2. Что подтверждено кодом

- **Минимизация:** `bot/services.py: get_or_create_user` не сохраняет имя и username; тест `test_names_are_not_stored`.
- **Согласие на учёт источника:** `bot/handlers.py: cmd_start`, `cb_consent`, `pending_sources`, `count_source`. Тесты:
  - `test_source_saved_once_and_shown_in_stats`;
  - `test_analytics_consent_only_asked_with_source_and_is_optional`;
  - `test_day1_is_free_and_needs_no_consent`.
- **Права субъекта:** `bot/privacy.py` — `/privacy` (сведения, отзыв, удаление), `destroy()`, `/forget` (то же для обращений вне бота). Тесты:
  - `test_privacy_access_request_is_registered`;
  - `test_analytics_withdraw`;
  - `test_destroy_free_user_deletes_everything`;
  - `test_destroy_paid_user_keeps_legal_records_with_date`;
  - `test_forget_keeps_payments`.
- **Сроки хранения:** `purge_expired()` раз в сутки из планировщика. Тесты `test_purge_expired`, `test_paid_retention_until`.
- **Поддержка:** предупреждение о специальных категориях; `/close` удаляет обращение из чата администратора; reply с командой не пересылается пользователю. Тесты `test_support_prompt_warns_about_health_data`, `test_admin_close_deletes_support_message_and_is_not_relayed`.
- **Отсутствие входящих подключений:** webhook удаляется при запуске (`main.py`), обновления получаются через long polling; HTTP-порт отвечает только «ok» (`start_health_server`).
- **Журналы:** логируются Telegram ID, номера дней, идентификаторы платежей и заявлений; тексты сообщений и обращений не логируются (проверено поиском по `log.*` в `bot/`).

## 4. Остающиеся риски

1. **Трансграничная передача через Telegram** без уведомления, если юрист её подтвердит (ст. 12; ст. 13.11 КоАП).
2. **Уведомление об обработке не подано**, если оно обязательно (ст. 22; ст. 13.11 КоАП).
3. **Локализация** не подтверждена документально.
4. **Сообщения в инфраструктуре Telegram** удалить нельзя — ограничение указано в политике (п. 9.5).
5. **Ручные процедуры** (уточнение, прекращение обработки, неправомерная обработка) зависят от того, соблюдает ли Оператор сроки.
6. ~~Метка в памяти процесса до согласия~~ — устранено: метка передаётся только в данных кнопки и записывается лишь после нажатия «Да, можно учитывать». Отказ («Нет, не нужно») ничего не записывает.
