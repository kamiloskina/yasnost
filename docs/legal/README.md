## Как опубликовать
1. После правок исходников (`*.md`) пересобрать версии для публикации: `python3 docs/legal/build_publish.py`.
2. Опубликовать каждый файл из `publish/` отдельной страницей (например, на telegra.ph).
3. Вставить ссылки в Amvera → Variables: `OFFER_URL`, `PRIVACY_URL`, `CONSENT_URL`. Бот покажет их в согласии, перед оплатой и в /terms. Без них бот в режиме оплаты не запустится.

Если меняешь текст документов - увеличь `DOC_VERSION`: пользователи подтвердят новую редакцию, уже заключённые договоры не меняются.
