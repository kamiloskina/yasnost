# Юридические документы

| Файл | Что это |
|---|---|
| `offer.md` | Публичная оферта: бесплатный День 1 + шесть платных этапов (дни 2–7) за 990 ₽, по 165 ₽ за этап |
| `privacy.md` | Политика обработки персональных данных (152-ФЗ) |
| `consent.md` | Согласие на обработку персональных данных (даётся кнопкой в боте перед Днём 1) |
| `legal-audit.md` | Аудит: найденные нарушения, исправления, нормы, вопросы для юриста |
| `compliance-checklist.md` | Что оператору сделать самой перед продажами и после запуска |

Документы заполнены данными исполнителя, редакция от 07.11.2026 (в боте — `DOC_VERSION = "2026-11-07"` в `bot/legal.py`). Это не юридическая консультация: пункты `LEGAL_REVIEW_REQUIRED` нужно подтвердить у юриста.

## Как опубликовать
1. Удалить пометки `LEGAL_REVIEW_REQUIRED` после проверки юристом.
2. Опубликовать каждый документ отдельной страницей (например, на telegra.ph).
3. Вставить ссылки в Amvera → Variables: `OFFER_URL`, `PRIVACY_URL`, `CONSENT_URL`. Бот покажет их в согласии, перед оплатой и в /terms. Без них бот в режиме оплаты не запустится.

Если меняешь текст документов — увеличь `DOC_VERSION`: пользователи подтвердят новую редакцию, уже заключённые договоры не меняются.
