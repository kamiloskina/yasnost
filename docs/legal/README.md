## Как опубликовать
2. Опубликуй каждый документ отдельной страницей, например на telegra.ph (бесплатно, без регистрации).
3. Вставь ссылки в Railway → Variables: `OFFER_URL` и `PRIVACY_URL`. Бот покажет их перед оплатой и в /terms.

## Чек-лист перед реальными продажами
- [ ] Статус самозанятой активен, в «Мой налог» нет ограничений на этот вид дохода.
- [ ] Подключена ЮKassa для самозанятых (или выбран Telegram Stars — см. `docs/marketing/strategy.md`, раздел «Оплата»).
- [ ] Чеки: при ЮKassa для самозанятых доход регистрируется в «Мой налог» автоматически — проверить в настройках магазина.
- [ ] Оферта и политика опубликованы, ссылки вписаны в переменные.
- [x] Поддержка — через /paysupport в боте (обращения приходят администраторам), e-mail в оферте.
- [ ] Условия возврата в `/terms` (3 дня, стоимость неоткрытых дней) совпадают с офертой (раздел 6).
- [ ] Показать раздел 6 юристу: право потребителя на отказ от услуги (ст. 32 ЗоЗПП) ограничить полностью нельзя, поэтому возврат считается по неоткрытым дням.
- [ ] `DEBUG_COMMANDS=false`.
