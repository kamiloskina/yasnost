# ElevenLabs: День 1. «Кто ты, когда никто не видит»

## Настройки (для всех фрагментов одинаковые)

- Голос: один и тот же для всех фрагментов (созданный в Voice Design или клон твоего голоса).
- Модель: Multilingual (последняя версия с поддержкой русского и тегов пауз `<break>`).
- Stability: 65-70%
- Similarity: 75%
- Style: 0-10%
- Speed: 0,85-0,9
- Speaker boost: включён

## Как работать

1. Каждый фрагмент вставляй и озвучивай **отдельно**. Скачивай MP3 и называй по номеру: `01.mp3`, `02.mp3`…
2. Внутри фрагментов короткие паузы уже стоят: тег `<break time="1.5s" />` и многоточие.
3. После фрагмента написано, сколько секунд **тишины** поставить при склейке. Тишину добавляешь в GarageBand: просто отодвигаешь следующий кусок на нужное число секунд.
4. В начале всей записи 5-10 секунд одной музыки (если она есть), в конце 10-15 секунд.
5. Если какое-то слово прозвучало с неправильным ударением, перегенерируй только этот фрагмент. Не помогло - замени слово синонимом или поставь ударную гласную заглавной (например, «сОбираешься») и проверь.
6. Тег вставляй именно в таком виде: `<break time="1.5s" />`. Не больше 3 секунд в одном теге.

Итоговая длительность: около 9-11 минут.

## Фрагменты

**01**
```
Добро пожаловать на практику «Кто ты, когда никто не видит». <break time="1.2s" /> Устройся поудобнее, так, как удобно именно тебе: сидя, лёжа или полулёжа, на подушках. <break time="0.8s" /> Главное, чтобы телу было спокойно и ничего не мешало.
```
→ тишина **5 сек**

**02**
```
Если хочешь, закрой глаза. <break time="1s" /> Или просто опусти взгляд.
```
→ тишина **5 сек**

**03**
```
Сделай медленный вдох… <break time="2.5s" /> и долгий выдох.
```
→ тишина **5 сек**

**04**
```
Ещё раз. <break time="1s" /> Вдох… <break time="2.5s" /> и выдох. <break time="1.5s" /> На выдохе позволь плечам опуститься чуть ниже, чем обычно.
```
→ тишина **8 сек**

**05**
```
И ещё один. <break time="1s" /> Вдох… <break time="2.5s" /> выдох.
```
→ тишина **10 сек**

**06**
```
Представь, что ты дома. <break time="1s" /> Одна. <break time="1s" /> Дверь закрыта. <break time="1.5s" /> Никто не придёт. <break time="0.8s" /> Никто не позвонит. <break time="0.8s" /> Никому ничего не нужно от тебя, <break time="0.5s" /> ни сегодня, ни в ближайшие часы.
```
→ тишина **10 сек**

**07**
```
Заметь, что меняется в теле, когда ты это представляешь. <break time="2s" /> Может быть, расслабляется лицо. <break time="1.2s" /> Может быть, становится непривычно… <break time="1s" /> или даже тревожно. <break time="1.2s" /> Может быть, хочется просто лечь. <break time="2s" /> Что бы ты ни почувствовала, это нормально. <break time="1.2s" /> Просто заметь. <break time="1s" /> Без оценки.
```
→ тишина **20 сек**

**08**
```
А теперь вспомни место, где ты обычно «собираешься». <break time="1.5s" /> Работа. <break time="0.8s" /> Семья. <break time="0.8s" /> Встреча с подругами. <break time="1.2s" /> Выбери одно.
```
→ тишина **8 сек**

**09**
```
Представь, как ты входишь туда. <break time="2s" /> Что происходит с твоим лицом? <break time="1.5s" /> С голосом? <break time="1.5s" /> Со спиной?
```
→ тишина **15 сек**

**10**
```
Какой ты становишься там? <break time="2s" /> Что ты надеваешь на себя, чтобы тебя приняли?
```
→ тишина **20 сек**

**11**
```
Дай этой роли имя. <break time="1s" /> Любое, первое, что придёт. <break time="1.5s" /> Например… <break time="1s" /> «Отличница». <break time="1s" /> «Спасательница». <break time="1s" /> «Железная». <break time="1s" /> «Мне всё равно».
```
→ тишина **15 сек**

**12**
```
Посмотри на неё. <break time="1.2s" /> Не ругай её. <break time="1.2s" /> Она появилась не просто так. <break time="1.5s" /> Когда-то она тебя защищала.
```
→ тишина **10 сек**

**13**
```
Мысленно скажи ей: <break time="1s" /> «Я вижу тебя. <break time="1s" /> Спасибо, что защищала меня».
```
→ тишина **15 сек**

**14**
```
И добавь: <break time="1s" /> «Теперь я могу выбирать, когда ты мне нужна».
```
→ тишина **15 сек**

**15**
```
Вернись вниманием к дыханию. <break time="1.5s" /> Вдох… <break time="2.5s" /> выдох.
```
→ тишина **8 сек**

**16**
```
А теперь просто побудь с собой. <break time="1.5s" /> Почувствуй всё тело целиком, от макушки до кончиков пальцев.
```
→ тишина **10 сек**

**17**
```
Заметь, где сейчас тепло. <break time="1.2s" /> Где легко. <break time="1.2s" /> Где ещё осталось напряжение.
```
→ тишина **10 сек**

**18**
```
С каждым выдохом позволь ему уходить. <break time="1.5s" /> Разожми челюсть. <break time="1.2s" /> Отпусти плечи. <break time="1.2s" /> Расслабь руки.
```
→ тишина **15 сек**

**19**
```
Тебе сейчас ничего не нужно делать. <break time="1.5s" /> Никому ничего не нужно доказывать. <break time="1.5s" /> Можно просто быть.
```
→ тишина **20 сек**

**20**
```
Сделай глубокий вдох… <break time="2.5s" /> и на выдохе отпусти всё, что больше не нужно держать.
```
→ тишина **10 сек**

**21**
```
Почувствуй опору под собой: пол, стул или кровать. <break time="1.5s" /> Почувствуй, как она тебя держит. <break time="1.5s" /> Ты здесь.
```
→ тишина **8 сек**

**22**
```
Медленно пошевели пальцами рук и ног.
```
→ тишина **5 сек**

**23**
```
Когда будешь готова, открой глаза.
```
→ тишина **5 сек**

**24**
```
Не торопись вставать. <break time="1s" /> Побудь ещё немного в этом состоянии. <break time="2s" /> А когда захочешь, в боте тебя ждут несколько вопросов. <break time="0.8s" /> Ответь на них, пока ощущения ещё свежие.
```
→ конец, **10-15 сек** музыки или тишины

## Проверка перед загрузкой в бот

- Прослушай целиком в наушниках: везде один и тот же голос, без скачков громкости.
- Нет обрывов слов на стыках фрагментов.
- Ударения: «собираешься», «отпусти», «ощущения», «опору».
- Загрузка: `/audio` → День 1 → отправить файл → «Отправить N чел.» (тем, кто уже получил День 1 без аудио).
